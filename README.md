# TradPlus IronSource Adapter Swift Package

Swift Package Manager support for the TradPlus IronSource adapter (15.18.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-IronSource.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-IronSource.git", exact: "15.18.0")
```

Third-party dependency: IronSource SDK `9.7.0`. Minimum iOS 12.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.18.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
